# Quartus + Verilog 初学者教程（基于 DigitalClock 工程）

> 这份教程是给**会一点 C、没碰过 Verilog、没打开过 Quartus、没跑过仿真、没下载过板子**的人写的。
> 目标不是“把 15 个文件讲一遍”，而是让你**能自己打开工程、看懂代码、跑通仿真、改一个功能、下载到板子上**。

## 1. 这套教程和旧说明书的区别

旧说明书（`docs/01~05_*.md`）是**按“设计文档”写的**：讲原理、讲接口、讲波形，默认你已经知道怎么建工程、怎么加文件、`always` 是什么。初学者卡住的往往不是原理，而是：

- “新建工程向导第 2 页那个 Top-Level Entity 到底填什么？”
- “`assign` 和 `always` 有什么区别？”
- “点了 Start Compilation，然后呢？”
- “仿真跑了，波形窗口在哪？”
- “下载完了没反应，从哪查？”

这套教程**从“你现在卡在哪”出发**：每一章都按“先讲为什么 → 再给可直接照做的步骤 → 再解释代码 → 最后给排错表”的顺序写，并且**每个操作都对应本工程的真实文件、真实菜单、真实引脚**。

| 旧说明书 | 本教程的对应 |
|---|---|
| 00_design_baseline / 00_board_config | 第 02 章（硬件与工程总览）、第 11 章（引脚表） |
| 01_key_manual（按键说明书） | 第 05 章（nibble_key / core_key / key_ctrl） |
| 02_divider_manual（分频器说明书） | 第 05 章 5.2（clk_gen）+ 第 06 章 6.7（buzzer_tone） |
| 03_architecture_manual（架构说明书） | 第 04 章（顶层与连线）+ 第 06 章（数据通路） |
| 04_simulation_manual（仿真说明书） | 第 08 章（仿真实战）+ 第 09 章（断点调试） |
| 05_final_plan（最终方案） | 第 10 章（上板与排错） |

## 3. 图例：三种图怎么区分

教程里的图分三类，看图时请注意区分：

| 类型 | 长什么样 | 说明 |
|---|---|---|
| **真实截图** | 有 Windows 标题栏、有 Quartus/ModelSim 的完整界面 | 就是这台电脑上 17.1 版本的真界面，可以直接对照着点 |
| **界面示意** | 右下角有橙色角标「界面示意（按 Quartus 17.1 布局重绘）」 | 按真实布局重绘的示意图（向导内页、下拉菜单这类抓不到静态截图的界面）。**字段名、按钮名、菜单路径都是真的**，只是画面是画的 |
| **原理图/时序图** | 白底、彩色方块、带箭头或时间轴 | 用来讲“信号怎么走”“为什么在这个时刻变”，不是软件界面 |

图都是用脚本生成的，想改可以直接改脚本重新出图：

```text
docs/tutorial/tools/make_figures.py        # 原理图、框图、时序图（11 张）
docs/tutorial/tools/make_ui_figures.py     # 界面示意图（5 张）+ C/Verilog 对照 + 编译流程 + 数据流
```

运行方式（需要 Python + Pillow）：

```powershell
python docs/tutorial/tools/make_figures.py
python docs/tutorial/tools/make_ui_figures.py
```

## 4. 本工程的环境信息（教程里反复用到）

| 项目 | 值 |
|---|---|
| 软件 | Quartus Prime **Standard Edition 17.1**（`%QUARTUS_ROOTDIR%\bin64\quartus.exe`，`%QUARTUS_ROOTDIR%` 即安装目录） |
| 仿真器 | ModelSim-ASE 10.5b（`%QUARTUS_ROOTDIR%\..\modelsim_ase\win32aloem\vsim.exe`） |
| 器件 | Cyclone 10 LP `10CL006YU256C8G`（核心板若是 10CL010，改成 `10CL010YU256C8G`，引脚不变） |
| 实验箱 | 杭州康芯 KX-MS65，模式拨到 **No.9** |
| 时钟 | 50 MHz，引脚 `M15` |
| 工程文件 | `DigitalClock.qpf` / `.qsf` / `.sdc` |
| 编译结果 | 0 error / 1 warning（AN447 3.3 V 提示）、1 584 LE（25%）、680 寄存器、58 I/O |
| 仿真结果 | 82 PASS / 0 ERROR |
| 下载文件 | `output_files/DigitalClock.sof` |

## 5. 学习顺序建议（三种人三种读法）

**① 完全没接触过 FPGA（按顺序读）**

```text
01 换思维 → 02 认门 → 03 编译通过 → 04 看连线 → 05/06 逐模块 → 08 仿真 → 09 断点 → 10 上板
```

**② 只想尽快交作业/上板演示**

```text
03 的 3.3 打开工程 + 3.5 编译 + 3.7 下载 → 10 的 10.5 演示脚本 → 遇到问题查 10 的排错表
```

**③ 想把某个模块彻底搞懂**

```text
先看 05/06 对应小节 → 再看 07 里该模块用到的语法 → 然后 08 里对应的波形 → 最后 09 里设断点自己验证
```

## 6. 每章的约定

- 每章开头都有一张表：**学完你能做什么 / 前置知识 / 对应源文件 / 预计耗时**。
- 每章结尾都有 **本章小结** 和 **练习**，答案就在同章末尾（部分章用 `<details>` 折叠，点开才看得到）。
- 代码块都标了语言：`verilog` / `tcl` / `text` / `powershell` / `bat`。
- 代码一律取自本工程：**逻辑与行号都和源文件对得上**；源文件里带行尾注释的版本更详细，文档为版面只保留关键注释（要看全注释请直接开 `rtl/`）。
- 引脚号、器件型号、资源数字都来自 `DigitalClock.qsf`、`DigitalClock.sdc`、`output_files/*.summary` 与 `quartus_compile.log`。
- 术语第一次出现给英文，例如“综合（Synthesis）”“适配（Fitter）”。
