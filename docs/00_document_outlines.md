# 6. 五份文档的写作顺序与依赖

```text
《总体设计基线》
      │
      ├──►《系统架构说明书》──► 需要顶层和模块接口
      │
      ├──►《分频器说明书》────► 需要 clk_gen/buzzer_tone 代码
      │
      ├──►《按键操作说明书》──► 需要 key_input/key_ctrl 代码
      │
      └──►《仿真操作流程说明书》► 需要 testbench、波形、截图
                                  │
                                  ▼
                            《最终方案》
```

建议写作顺序：

1. 系统架构说明书（先锁接口）
2. 分频器说明书
3. 按键操作说明书
4. 仿真操作流程说明书
5. 最终方案
