# 电子时钟项目文档方案（待确认）

## 0. 先说结论

你的流程“先定方案、确认后再写”是对的，但建议调整顺序：

> **先写一份《总体设计基线》（大方案）→ 再写五份说明书的目录/要点（分方案）→ 确认后写 RTL、testbench、Quartus 工程并跑通仿真 → 最后写五份说明书正文和《最终方案》。**

不建议一上来同时写五份完整说明书。原因是：

1. 五份文档都要引用同一套引脚、按键、模块接口；先写正文容易出现前后不一致。
2. 仿真说明书必须引用真实的 testbench、波形和截图；代码没跑通就写，只能编，后面还要返工。
3. 初学者文档需要“先总后分”：先知道系统怎么组成，再看按键、分频器、仿真，理解成本最低。

所以建议的节奏是：

```text
第 1 步：总体设计基线（大方案）        ← 先定接口和行为
第 2 步：五份说明书的目录和要点（分方案） ← 你确认
第 3 步：RTL + testbench + Quartus 工程  ← 代码实现
第 4 步：编译、仿真、上板验证            ← 拿到真实结果
第 5 步：写五份说明书正文 + 最终方案      ← 用真实代码和波形写
第 6 步：统一格式，导出 DOCX/PDF          ← 提交版
```

## 2. 五份说明书的方案

### 2.1 《按键操作说明书》

**目标读者**：第一次接触模式 9 按键、看不懂 PI/PIO 的初学者。

**要回答的问题**：

- 8 个模式 9 按键分别接在哪里？
- 为什么按一次是 4 位二进制加 1？
- FPGA 为什么不能清零？怎么检测按下？
- 核心板 K1～K4 分别做什么？
- 每个模式下按键是什么功能？
- 代码里哪个模块负责按键？顶层怎么连？

**目录**：

1. 本章目标与前置知识
   - 什么是 nibble、低有效、消抖、同步
2. 硬件连接
   - 模式 9 键 1～8 的 nibble 与 FPGA 引脚表
   - 核心板 K1～K4 引脚表
   - PI/PIO 是输入，不能由 FPGA 驱动
3. 模式 9 按键原理
   - 4 位计数器：0000→0001→0010→…→1111→0000
   - 为什么不能清零；影子寄存器 `prev`
   - 两级同步 + 20 ms 稳定 + 变化检测
   - 按键时序图
4. 核心板按键
   - 低有效、20 ms 消抖
   - K2/K3 连加连减：0.5 s 延时、10 Hz 重复
   - K1 复位、K4 进入/确认
5. 按键映射与操作逻辑
   - CL/AL/St/Cd 四模式总表
   - 模式状态机
   - 设置子状态机、光标移动、数字范围
   - 键 8 取消、后台计时、0 启动不响
6. 代码讲解
   - `key_input.v`：同步、消抖、nibble 变化检测、核心键连发
   - `key_ctrl.v`：模式/设置状态机、按键动作译码
   - 顶层例化与信号连接
   - 如何改键位（只改一处映射）
7. 仿真与上板验证
   - 按键变化检测 testbench
   - 模式切换、设置、确认/取消波形
   - 常见问题：没反应、按 16 次回绕、上电初值、按住不连发
8. 本章小结与练习
   - 交换键 1/键 2
   - 增加一个“按键测试模式”

**预计篇幅**：15～20 页。

### 2.2 《分频器说明书》

**目标读者**：会基本计数器，但不懂“为什么不能拿分频输出当时钟”的初学者。

**要回答的问题**：

- 50 MHz 怎么变成 1 Hz、100 Hz、1 kHz、2 Hz？
- 为什么用“单周期使能”，不用分频时钟？
- 计数器位宽怎么算？
- 蜂鸣器 2.7 kHz 方波怎么产生？
- 代码在哪里？怎么仿真？

**目录**：

1. 本章目标与前置知识
   - 频率、周期、占空比、计数器
2. 硬件连接
   - `M15` 50 MHz 晶振
   - `T13` 无源蜂鸣器，PNP 低有效
3. 分频原理
   - 分频公式
   - 计数器从 0 计到 N−1
   - 50 MHz → 1 Hz / 100 Hz / 1 kHz / 2 Hz 的计算表
   - 为什么用 tick 使能：单时钟域、避免门控时钟、便于时序分析
4. `clk_gen` 模块
   - 端口与参数
   - 各计数器位宽
   - `tick_1hz`、`tick_100hz`、`tick_1khz`、`tick_2hz`
   - 复位后的初值
5. 蜂鸣器音频分频
   - 2.7 kHz 方波
   - 翻转计数 9,259 的计算
   - `buzzer_tone` 模块
   - 低有效输出与 PNP 驱动
6. 代码讲解
   - 完整代码，逐行中文注释
   - 参数化仿真：把 50,000,000 改小
7. 仿真
   - 测周期、占空比、tick 宽度
   - 1 Hz 使能与 1 kHz 扫描的关系
   - 波形截图与 3～5 个关键点分析
8. 上板验证（可选）
   - 用 LED 看 1 Hz
   - 用示波器/逻辑分析仪看蜂鸣器波形
9. 常见问题
   - 没有 tick、频率不对、计数器位宽不够、仿真太慢、门控时钟警告
10. 本章小结与练习
    - 增加 10 Hz tick
    - 把 1 Hz 改成 2 Hz

**预计篇幅**：10～15 页。

## 4. 写作规范

- 中文为主，术语第一次出现时给英文和解释。
- 每章开头写“学完你能做什么”“前置知识”。
- 每章结尾写“本章小结”“练习”。
- 代码全部中文注释；关键语句逐行解释。
- 每个功能配“原理图/框图 + 代码 + 波形 + 上板现象”。
- 波形分析按课程要求选 3～5 个关键点，说明“为什么变”。
- 引脚表统一格式：信号名、位、FPGA 引脚、实验箱信号、有效电平。
- 常见错误单独成节，用“现象→原因→解决”格式。
- 图片统一放 `docs/images/`，编号 `图1-1`、`图2-3`。
